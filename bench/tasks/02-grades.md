# Task: grades

Define a type with exactly three cases: `Pass`, `Fail`, and `Incomplete`.

Write a function that turns a score into one of them:

- a score of 50 or more is `Pass`
- a score below 0 is `Incomplete`
- anything else is `Fail`

For each score in `[75, 30, -1]`, print the score and the name of its case.

## Expected output, exactly

```
75: Pass
30: Fail
-1: Incomplete
```
