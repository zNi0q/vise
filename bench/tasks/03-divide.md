# Task: divide

Write a division function that cannot fail at runtime: dividing by zero must be
reported as a value rather than crashing the program.

For each pair in `[(10, 2), (7, 0), (9, 3)]`, print the result, or `error` when
the divisor is zero.

## Expected output, exactly

```
10 / 2 = 5
7 / 0 = error
9 / 3 = 3
```
